# site-walker — Operator Documentation

This directory holds documentation for **operators** — anyone running their own
site-walker instance, or administering websites on a shared one.

It is **not** the place for internal development notes. Those live in
[`../dev-notes/`](../dev-notes/) and are written for the people building this
project.

## What will live here

As Phase 1 and Phase 2 progress, this directory will fill out with at least:

- **Self-hosting guide** — installation, MariaDB setup, environment variables, running under PM2 / systemd.
- **Website admin guide** — creating a website, managing the origin allowlist, setting welcome messages, configuring system blocks.
- **CLI reference** — full `./bin/sw` command reference.
- **WordPress plugin integration** — once the plugin project exists, how to point it at this API.
- **Operations** — backups, log inspection, conversation review.
